# ВайРассрочка

Бесплатное веб-приложение для жителей Чеченской Республики: личный учёт рассрочек и котла и публичная лента настоящих покупок людей. Для людей, а не для продавцов.

Состояние: готовы сервер, сайт (PWA), панель владельца, push и расчёт платежей; подготовлено развёртывание (`docs/DEPLOY.md`). Проверка: `npm install` и `npm run check`. Посмотреть своими глазами на компьютере: `npm run dev:memory -w @vayrassrochka/api` и `npm run dev -w @vayrassrochka/web` (данные в памяти).

Документы: `docs/SPEC.md` (что делаем), `docs/DESIGN.md` (как выглядит), `docs/TECH.md` (технологии), `docs/BACKLOG.md` (отложено), `CLAUDE.md` (правила работы).
