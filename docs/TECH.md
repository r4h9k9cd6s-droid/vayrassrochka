# Технологии (предложение, ждёт согласия владельца)

Статус: **предложено**, не утверждено. До утверждения не создавать каркас приложения.

Цель: недорого, быстро, просто в сопровождении, размещение в России, PWA на телефоне и ПК.

| Часть | Предложение | Почему |
|---|---|---|
| Язык | TypeScript везде | Один язык для сайта, сервера и расчёта платежей |
| Сайт | React + Vite + vite-plugin-pwa | Быстрый, ставится на главный экран, офлайн-кэш |
| Сервер | Node.js + Fastify | Лёгкий, быстрый |
| База | PostgreSQL + Drizzle ORM | Надёжно; миграции в коде |
| Расчёт платежей | Общий пакет `packages/shared` | Чистые функции и тесты (Vitest), один код на клиенте и сервере |
| Вход | Свой: логин+пароль (argon2), cookie-сессия, резервный код (хеш), TOTP для панели (otplib) | Без почты и телефона |
| Push | Web Push (библиотека `web-push`, VAPID) | Бесплатно |
| Обновление ленты | Периодический запрос / SSE (выбрать по простоте) | Без тяжёлых зависимостей |
| Развёртывание | Docker Compose на VPS, Caddy (https) | Одна команда обновления, дёшево |
| Резервные копии | Ежедневный дамп базы на отдельное хранилище | Требуется для запуска |

Структура репозитория (монорепозиторий, npm workspaces):
```
apps/web      сайт (PWA)
apps/api      сервер
packages/shared   типы и расчёт платежей (без зависимостей от сервера и сайта)
docs/         спецификация, дизайн, решения
```

Тесты: Vitest для расчёта платежей (обязательно покрыть все примеры из SPEC.md §3), интеграционные тесты API на тестовой базе; проверка тем и доступности вручную.

Ограничения среды: разработка идёт в облачной сессии; реальные push на iPhone/Android и публикацию на хостинг проверяет владелец на своих устройствах.
