# Отложено (не в первой версии)

Всё придумано и согласовано по смыслу, но выполняется только после проверки интереса к ядру.

| Функция | Что это | Почему позже |
|---|---|---|
| Долги | Раздел: «я должен» / «мне должны», остаток, срок необязателен, возвраты любыми суммами, не входят в расход месяца; никогда не публикуются | Расширяет продукт за пределы рассрочек |
| Регулярные платежи («Мои финансы») | Аренда, интернет, спортзал и т.п.; шаблоны, фиксированная/меняющаяся/редкая сумма, отметка «оплачено в месяце», дата окончания; вместе с долгами и котлом раздел «Мои финансы» | Другой продукт (бюджет), сначала проверить ядро |
| Слежка за товарами | «Следить за такими» + параметры (товар, платёж до), уведомления: до 3 в день сразу, остальное вечерней сводкой; экран «Что отслеживаю» | Нужна заполненная лента и подсказки названий |
| Сравнение цен | «Похожие покупки: N · от … до … · платёж …»; только зарегистрированным; показывать от 3 записей | Нужно достаточно данных |
| Отзывы о продавцах | Оценка 1–5 и комментарий; один отзыв на покупку | Модерация и защита от накрутки |
| Нагрузка по месяцам, дата свободы, личная подсказка «ниже среднего на N%» | Украшения Главной | Не ядро |
| Выписка по рассрочке (PDF), фото чека, совместный доступ | Практичные дополнения | Позже |
| Телефонная авторизация, запрет публикаций по номеру продавца | Правило согласовано, но требует подтверждённых номеров | Нет телефонов на старте |
| Выбор города/района, адрес как обязательное поле | Различать одноимённых продавцов | Обсудить позже |
| Роли в панели владельца (модератор) | Интерфейс управления командой | Когда будет второй администратор |
| Скрытие сумм глазком — уже в первой версии | — | — |
| Виджеты на рабочий стол | Не обещать для всех платформ | Позже |

## Идеи, которые обсуждались и пока не берём
Доходы и «остаётся после платежей», бюджеты, категории расходов.
