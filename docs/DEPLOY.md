# Как запустить ВайРассрочку (этап 10)

Статус: **файлы готовы, ничего не запущено и не куплено.** Запуск в интернете делается только по вашей команде.

## Что понадобится (решения за вами)
1. **Сервер (VPS) в России** с Docker. Подойдёт самый простой тариф: 2 ГБ памяти, 20 ГБ диска.
2. **Домен** (в документах — vayrassrochka.ru, занятость не проверена).
3. **Отдельное хранилище для копий базы** (другой сервер или облачное хранилище в России). Требование для запуска: копии на том же сервере не спасут при поломке сервера.
4. **Юридическая проверка** правил сервиса и персональных данных до открытого запуска (SPEC §10, п. 5).

## Быстрый путь для теста
На чистом сервере Ubuntu (от root): `curl -fsSL https://raw.githubusercontent.com/r4h9k9cd6s-droid/vayrassrochka/<ветка>/deploy/install.sh | BRANCH=<ветка> bash`. Скрипт ставит Docker, скачивает код, создаёт пароли и ключи на самом сервере и запускает сайт. Без своего домена берётся адрес вида `1-2-3-4.sslip.io` с рабочим https. Для закрытого репозитория добавьте `GIT_TOKEN` (токен только для чтения).

## Шаги вручную (когда решения приняты)
1. На сервере: `git clone` репозитория.
2. `cp .env.example .env` и заполнить (пароль базы, домен, адрес сайта). Файл `.env` никому не показывать и в репозиторий не добавлять.
3. Ключи push: `npx web-push generate-vapid-keys`, записать в `.env`.
4. В `.env`: `COOKIE_SECURE=1` (когда включён https).
5. `docker compose up -d --build`. Https-сертификат Caddy получит сам, когда домен указывает на сервер.
6. Создать владельца: `docker compose exec api npx tsx apps/api/src/cli/create-admin.ts <логин>`. Пароль вводится в терминале; секрет для приложения-аутентификатора и резервные коды печатаются один раз, сохраните их.
7. Панель владельца: `https://<домен>/admin`.

## Обновление
`git pull && docker compose up -d --build`. Миграции базы применяются сами при запуске сервера.

## Резервные копии
Контейнер `backup` раз в сутки кладёт сжатый дамп в папку `backups/` (хранится 14 дней). **Эту папку нужно регулярно отправлять на отдельное хранилище** (например, `rclone` или `rsync` по расписанию `cron`). Восстановление:
`gunzip -c backups/db_ДАТА.sql.gz | docker compose exec -T db psql -U vayrassrochka vayrassrochka`

## Проверить до открытия для людей (чек-лист закрытого теста)
- Регистрация, резервный код, сброс пароля по коду.
- Добавление рассрочки, платёж, переплата, недоплата, пропуск, отмена.
- Публикация в ленту, карточка, ссылка WhatsApp, «Удалось связаться?», жалоба.
- Push на вашем Android и на iPhone (после «Добавить на главный экран»): за день, в день платежа, просрочка.
- Установка на главный экран, работа без интернета (лента и свои платежи видны, оплату без сети сохранить нельзя).
- Светлая и тёмная темы, крупный шрифт, контраст.
- Вход в панель владельца с кодом из приложения.
- Восстановление базы из копии на тестовом сервере.

## Что не проверено в облачной среде
Здесь нет Docker, поэтому образы не собирались, а https и настоящие push (Android/iPhone) не проверялись. Сервер и сайт проверены вручную с настоящим PostgreSQL 16, автотестами и в браузере.
